# 🌱 AgroSim | Simulador de Margem Agrícola

O **AgroSim** é uma ferramenta web interativa que auxilia produtores rurais a tomarem decisões financeiras mais assertivas. O objetivo é simular a margem de lucro de uma safra com base nos custos de produção e na cotação do mercado.

## 🚀 Funcionalidades
- **Inputs Dinâmicos:** O usuário insere a cultura (Soja, Milho, Café), o custo de produção por hectare, a produtividade (em sacas) e o preço atual da saca.
- **Cálculo em Tempo Real:** O sistema calcula automaticamente a Receita Bruta e o Lucro/Prejuízo.
- **Feedback Visual:** O valor do lucro fica verde se positivo e vermelho se for prejuízo.
- **Gráfico Comparativo:** Um gráfico de barras dinâmico mostra a proporção entre Custo e Receita, facilitando a visualização do balanço financeiro.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Formulários e estrutura semântica.
- **CSS3:** Design responsivo com tema dark (inspirado em dashboards financeiros).
- **JavaScript:** Lógica de cálculo matemático, manipulação de DOM e integração com a biblioteca de gráficos.
- **Chart.js:** Biblioteca open-source utilizada para renderizar o gráfico de barras de forma animada e responsiva.

## 💡 Por que este projeto é importante?
No agronegócio, a margem de lucro costuma ser apertada. Muitos produtores calculam seus custos no papel ou em planilhas complexas. O AgroSim simplifica essa dor, oferecendo uma interface intuitiva que qualquer pessoa consegue usar no celular, no meio do campo.
